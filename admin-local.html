LOCAL CONTENT MANAGER

Panel administracyjny.

Zarządzaj kategoriami i realizacjami bez edytowania kodu. Panel zapisuje dane i multimedia wyłącznie w wybranym folderze projektu na Twoim komputerze.

Publikowanie: możesz połączyć panel z GitHubem przez Fine-grained Personal Access Token (Contents: Read and write, wyłącznie repozytorium NeyeReQ/portfolio). Token jest używany tylko w pamięci tej karty, nie trafia do plików ani localStorage i znika po odświeżeniu strony. Alternatywnie nadal możesz wybrać lokalny folder i publikować przez GitHub Desktop. Nie wklejaj tokenu w czacie ani do plików repozytorium.

01 / Połącz GitHub — publikacja bez GitHub Desktop

Wygeneruj Fine-grained token na GitHubie. Wybierz tylko repozytorium NeyeReQ/portfolio i nadaj uprawnienie Contents: Read and write (Metadata: Read-only jest dodawane automatycznie). Zalecana krótka data wygaśnięcia.

Otwórz portfolio

Po połączeniu dodawanie lub usuwanie pracy tworzy jeden commit w gałęzi main. Multimedia i plik danych trafiają razem do repozytorium, a GitHub Pages uruchamia publikację automatycznie.

Najpierw połącz GitHub lub wybierz lokalny folder projektu.
