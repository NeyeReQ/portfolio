# Tła kafli „Grafika” i „Montaż”

Wgraj do tego folderu dwa pliki PNG o dokładnych nazwach:

- `grafika.png` — tło kafla „Grafika”
- `montaz.png` — tło kafla „Montaż”

## Wymiary

**1220 × 780 px** (proporcje 61:39).

Na dużym ekranie każdy kafel ma około 610 × 390 px, więc 1220 × 780 px zapewnia dwukrotną rozdzielczość. Na wąskich ekranach kafel staje się wyższy i obraz jest kadrowany do środka — najważniejsze elementy umieść centralnie.

## Przezroczystość

Strona automatycznie ustawia widoczność obrazu na **26%**; po najechaniu kursorem wzrasta ona do **35%**. Zapisz plik PNG normalnie, z pełnym kryciem — nie zmniejszaj ręcznie opacity, bo strona robi to za Ciebie.

## Dokładne ścieżki

- `assets/category-backgrounds/grafika.png`
- `assets/category-backgrounds/montaz.png`

Aby dodać grafiki, otwórz ten folder na GitHubie, wybierz **Add file → Upload files**, dodaj oba obrazy i zatwierdź commit na gałęzi `main`.
